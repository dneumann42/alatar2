# Alatar desktop themes

Open Nomicon and choose a **Theme**. Every bar, Nomicon, SystemDUI, and
Sleuth UI window running the shared-theme build picks up the selection on
its next theme refresh, about 150 ms. The choice persists across launches.
The existing dark-mode control picks the light or dark variant of the theme.

Parchment is the warm default, based on the original bar. Walnut, Slate,
and Evergreen come with light and dark variants. Wallust follows the
wallpaper palette generated by the desktop's existing Wallust configuration.
It uses Parchment's colors until there is a generated palette.

## Custom themes

Save a `.conf` file under `${XDG_CONFIG_HOME:-$HOME/.config}/alatar/themes/`.
The filename without the extension appears in Nomicon. For example,
`Copper.conf` can contain these overrides.

```ini
light.background = #ddccbd
light.surface = #c8aa93
light.accent = #70452e
light.on_accent = #fff3df

dark.background = #33251e
dark.surface = #49352a
dark.accent = #d1a17c
dark.on_accent = #251810
```

Available roles are `background`, `surface`, `text`, `muted`, `accent`,
`accent2`, `border`, `urgent`, and `on_accent`. An unprefixed role applies
to both modes. Omitted roles use the corresponding Parchment color.
Changes to the selected file apply live.

The applications read the same selection file under
`${XDG_CONFIG_HOME:-$HOME/.config}/alatar/theme`. SystemDUI and Sleuth find
the shared source in `~/.alatar` at build time. Set `ALATAR_ROOT` when
building from a different checkout location.

## Background opacity

Set `opacity` from `0.0` (clear) to `1.0` (solid). Use
`light.opacity` and `dark.opacity` for different values by mode. Built-in
themes default to `0.85`. Wallust uses the alpha from its generated palette.
To adjust a built-in theme, use a file with its name, such as
`Parchment.conf` or `Wallust.conf`, in the same themes directory.

```ini
opacity = 0.78
dark.opacity = 0.88
```

Wayland composites the background fills with the scene behind the window.
Text and icons keep their own opacity. Overlapping translucent fills blend
with one another.
