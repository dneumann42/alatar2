#+TITLE: Alatar

Alatar is a declarative system bootstrap and configuration manager for Arch
Linux. A module groups the packages, files, symlinks, and systemd units
needed for a task or desktop feature. Modules can depend on other modules,
and Alatar can install, inspect, or remove them from any working directory.

* Bootstrap

Run =./setup= on Arch Linux. It builds Alatar and the applications from
[[https://github.com/dneumann42/alatar-applications][alatar-applications]].
The application build chooses the GUI when SDL3 and Wayland development
libraries are present. Set =ALATAR_APP_BACKEND=tui= to force terminal-only
binaries, or =ALATAR_APP_BACKEND=gui= to require GUI support.

Alatar reads modules from =$XDG_CONFIG_HOME/alatar/modules=, with
=~/.config= as the fallback for XDG_CONFIG_HOME. Override the location with
=ALATAR_MODULES_DIR= or =--dir=. For the Sway desktop configuration and its
bar and tray build, see [[https://github.com/dneumann42/alatar-desktop][alatar-desktop]].

* Using modules

Put modules under =$XDG_CONFIG_HOME/alatar/modules= and use =alatar modules=
to list them. Use =alatar info NAME= to inspect a module and
=alatar install NAME= to apply it. The [[file:docs/modules.org][module reference]]
describes the supported files, native systemd units, and installation order.
